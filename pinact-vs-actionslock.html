pinact

ワークフロー YAML の uses をフル SHA へ書き換え、バージョンコメントとの対応を GitHub API で照合する。固定した SHA が PR の差分にそのまま見えるので、レビューで人が確認できる。更新は Renovate が回す。対象外は、action の内側で使われる推移的な action（実行時に解決される分は固定できない）。

gh actions-lock（workflow lockfile）

actions.lock に固定を記録し、runner が実行時に照合する。推移的な action まで固定でき、fork にしか無い commit を拒否できる点は pinact より強い。一方で、別 repo の reusable workflow と container image は対象外。固定が別ファイルに隠れるので差分レビューでは見えにくい。2026-10-28 に GA した直後で CLI は 1.0 前、Renovate が更新を直せるかは未確認。

併用できないのが要点pinact が uses を SHA へ書き換えると lockfile と合わなくなるため、乗り換えは pinact を外すことを意味する。lockfile 対応は pinact 側の Issue 1828 で追跡中
