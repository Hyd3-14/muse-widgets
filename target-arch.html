目標の形 — 層ごとに置き場所と予算を固定する

L0 全体df の全体 AGENTS.md 1枚（正本）
原則とポインタだけ。各ハーネスの入口ファイル（CLAUDE.md／GEMINI.md 等）はここへの参照だけにし、df が配布する。目安は約1,200トークン
L1 入口home repo（案Cで作成中）
セッションの開始点。repo へのポインタとルーターだけを持ち、内容は持たない
L2 repo各 repo の AGENTS.md＋GLOSSARY.md＋repo 固有 Skill
AGENTS.md は navigation だけ。固有の Skill と hook はその repo の中に閉じる
L3 作業spec と tickets（Issue）
セッションが読むのは対象 ticket と frontier だけ。終わったら成果と決定は repo と vault へ戻す

横断の決めごと：制約（守らせるもの）は文章ではなく repo の lint／CI／hook コードに置く。知識と決定の正本は vault。Skills は正本1か所から全ハーネスへ配布し、入口は resident（常駐・少数）と routed（ルーター経由）の2段にする。
