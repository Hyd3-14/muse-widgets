↓
Cloudflare Access：本人確認。メールアドレスのワンタイム PIN で入れるため、GitHub アカウントを持たない塾長でも使える。無料枠は50人まで
↓
Worker（シートのページ）：ログインした人のメールから、その人が決める分だけを表示。回答を受けたら GitHub へ書き戻す。アプリ本体とは別の小さな Worker にする
↓
GitHub Issues（正本）：Issue 本文に決定メタデータ（決める人・選択肢・推奨・既定値・期限）を機械可読な形で埋め、回答は決定記録コメント＋ラベル変更として残る
脇の2本：未決定点の抽出とメタデータ付けは Agent が行う。期限を過ぎた無回答は、定期実行が既定値を確定してラベルを進める
