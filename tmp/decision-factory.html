意思決定のソフトウェアファクトリー
決定待ち Issue を、回答できる形にして、決まったら自動で実装側へ流す
1. 抽出：Agent が C の Issue から未決定点を抜き出し、メタデータを付ける。誰が決めるか（tantan／tomo／kaito／塾長）、選択肢、推奨、既定値、期限
2. 回答：意思決定シート（HTML）を決める人ごとにグループ表示。見る側は選ぶだけで回答でき、無回答は期限で既定値が確定する
3. 書き戻し：回答を Issue へ自動で反映する。決定記録のコメント、status を ready へ、決定を固定したブリーフの生成
4. 実装：B → A キューへ昇格し、自動実装 → PR。UI 変更は ui-diff の証跡、品質はテストのゲートで担保する
