OpenFamily を無料でクラウドに置く候補
Oracle Cloud Always Free 推し
ARM の仮想マシンが恒常無料（最大 4 OCPU / 24GB）。Docker がそのまま動くので OpenFamily を無改造で常時起動できる。弱点は登録にカードが要ること、空きがなくて作れないことがあること、長期間放置で回収される話があること。
Google Cloud e2-micro（無料枠）
仮想マシンとしては動くが、メモリ 1GB では Node と PostgreSQL の同居がぎりぎり。無料なのは米国リージョンだけなので、家族の使う時間帯の遅延も出る。
Render など無料 PaaS 系
無料枠はスリープする、ディスクが揮発する、無料 DB に期限がある、のどれかが必ず付く。家族のデータを置く場所としては不適。
Cloudflare Containers
Docker のまま載るが Workers Paid（月 $5 から）が必要で、無料ではない。ディスクの揮発性も残る。
