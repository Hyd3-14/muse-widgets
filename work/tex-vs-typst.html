LaTeX
Typst
導入とビルド
TeX Live は数 GB 級。コンパイルは秒単位で、複数回回すことも多い
単一バイナリで軽く、コンパイルはほぼ一瞬（差分で再計算）
エラー
ログが長く、原因の行とずれることが多い。慣れが要る
場所をソース上に示して、直し方のヒントも出す
数式
記法は重いが、表現力と実績は最大級
記法が短く読みやすい。高校数学の範囲は十分に書ける
図とグラフ
TikZ と emath の資産が厚い。日本の数学教材はここが強い
CeTZ や Lilaq があるが、資産はまだ育ちかけ
日本語組版
LuaLaTeX と jlreq で成熟。縦書きもできる
横書きは問題なし。縦書きはまだ弱い
相手が触る
環境構築の時点でつまずきやすい
Web 版（typst.app）は導入なしでプレビューを見ながら直せる
自動化
マクロは強力だが読み書きが難しい
普通のプログラムのように書ける。数値を変えた類題や、解答の自動生成がしやすい
太字はその項目で分がある側。教材プリントで効くのは「エラー」「相手が触る」「自動化」で、LaTeX が勝つのは「図の資産」と「日本語組版の成熟度」。
