muse-widgets demo

Every component in the catalog, live. The interactive ones run against an in-memory stand-in for the Muse state bridge, so state resets when this page reloads. Inside Muse, the same fragments persist their state with the conversation.

Unofficial project. See the repository for the catalog, the agent skill, and the validator.
