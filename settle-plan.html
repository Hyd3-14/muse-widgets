丸く収まる形：入口と正本を1つにして、増やす前に測る
ファイルを並べ替えるだけだと再発する。検知と prune のループまで入れて初めて閉じる。

進め方

1凍結と棚卸し新規追加を止め、live と正本の差分、参照切れ、重複 Skill を全部出す
2SSOTを決める全体指示の正本は df の AGENTS.md 1枚。入口ファイルは参照だけ
3配布を一本化Skills は df の lock から配布。入口は resident と routed の2段
4home repo 試験案Cの薄い殻で2週間。消費、差し戻し、開始時コンテキストを測る
5定期ループ化月次で実測と retro。参照切れと drift は自動で知らせる
Muse が引き受ける
  • 実測、差分表、設計、ファイル案、検証スクリプト案
  • df と vault の下書き、Issue と PR の準備
  • 試験の記録と比較、進捗の図解報告
お前さんの分は3つだけ
  • SSOT の最終決定（推しは df 1枚）
  • WSL2 の live 設定と権限を変える場面の承認
  • agy の実行（Muse は agy を使わない決めのため）
